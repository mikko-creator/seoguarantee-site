Count-up spec JS numeral tween · reads --ds-dur-data

100% sample numeral

Numerals (.bw-stat__n / .bw-metric__n / .bw-kpi__n) carry data-count + optional data-prefix/data-suffix; the markup already holds the FINAL value as text (renders-on-load-safe). On scroll-into-view a rAF tween eases 0→final with an ease-out cubic over --ds-dur-data = 1.4s (read at runtime). reduced-motion / no-JS → the final value paints immediately. The number never fades; only its TEXT counts.
