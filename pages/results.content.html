The standard

How a result gets measured, and how it gets permission.

Four things, plainly.

01

What is measured, and in what.

First page means page one of Google organic results for an agreed key phrase in an agreed geography. Every position published here is read in a named tool. It is never guessed: it is supplied per result, or the result does not publish.

02

Permission.

Every named client gave written permission to be named. Where permission is not on file the outcome is not published, and that holds even when the outcome is a good one.

03

Individual results vary.

Nothing on this page predicts what will happen for a different business, in a different market, against a different set of competitors.

04

We publish no overall figure for how often campaigns reach first page.

The honest answer is not a better-sounding number. It is evidence where every individual claim carries a date, a method, a tool and a permission.
