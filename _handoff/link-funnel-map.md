## §3 — The four funnels

**1. Sceptical researcher** *(the dominant path — the buyer arrives pre-objected)*
entry → `guarantee` → the objection answered in-page → `results` → **CALL US** → `contact-us` → `thank-you`
Derived from `D-MARKET-002`, which ranks for the client's own category term with a scam-warning article quoting Google Search Central. This funnel assumes the visitor has already read that argument.

**2. Service intent** *(new, created by the mega menu — D-005)*
entry (commercial search, e.g. "las vegas web design") → a service leaf → `full-suite` → `guarantee` → **CALL US**
Each of the 7 leaves carries its `included_line`, so a visitor arriving on a service page learns the bundling mechanic without needing the homepage. This is why the mega menu strengthens rather than dilutes the position.

**3. Vertical match**
entry (vertical query) → `industries-<vertical>` → `results` → `guarantee` → **CALL US**
`industries-law-firm` additionally carries the only operated proof of the pause mechanic.

**4. Local intent**
entry → `las-vegas-seo` or `our-locations` → `guarantee` → **CALL US**

**Every funnel terminates on the same action:** CALL US → `contact-us` → book a consultation. The live site's 5-way CTA split is eliminated.
